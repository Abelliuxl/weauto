# skill-authoring

- 用途: 当用户要求你增加能力、沉淀流程、写 skill、以后按固定套路处理某类事时，指导你创建或更新技能文件
- 触发词: skill, 技能, 加能力, 以后遇到, 固定流程, 自己写skill, 自己给自己写

## 规则
- 优先把“可复用、可长期执行”的流程写成 skill，不要只在当前回复里口头记住
- 技能文件路径统一使用 `skills/<skill_name>/SKILL.md`
- skill_name 要短、清晰、可复用，优先使用英文小写加连字符
- 如果已有相近 skill，优先更新，不重复造轮子
- 内容要写清触发条件、边界、禁止事项和执行步骤

## 步骤
1. 判断用户要的是临时回答，还是要你以后反复按同样方式做事
2. 如果是后者，先查看现有 skills 是否已有接近能力
3. 选一个稳定的 skill 名称，整理成 `用途 / 触发词 / 规则 / 步骤`
4. 用 `workspace_write_file` 写入或更新 `skills/<skill_name>/SKILL.md`
5. 完成后简短告诉用户你新增了什么能力、skill 文件在哪
