# PEOPLE_ALIASES.md

手工维护“同一个人不同名字”的映射。

写法（每行一条）：
- 标准名 -> 别名1, 别名2, 别名3

# 支持通配（OCR 名字前缀不稳定时用）：
# - *cong    => 后缀匹配（例如：饕餮cong、餮虢cong 都会命中）
# - cong*    => 前缀匹配
# - *cong*   => 包含匹配
