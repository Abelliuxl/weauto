# weather-query

## 用途
当用户询问天气、温度、降雨、风、冷不冷、热不热、出门穿什么、明天/周末天气等信息时使用。

## 触发词
天气、气温、温度、下雨、降雨、会不会下雨、冷不冷、热不热、风大、预报、穿什么、出门、明天、今天、周末。

## 规则
- 优先调用 `query_weather`，不要用网页搜索替代天气 API。
- 如果用户没有说地点，使用默认地点；如果上下文里有明确城市，也可以用上下文地点。
- 你负责根据用户问题填写 `location`、`mode`、`days`、`date` 或 `day_offset`；天气工具只负责按参数查询。
- 短问默认 `mode=both`、`days=3`；只问“现在”用 `mode=now`；只问未来某天用 `mode=forecast` 并填写 `date` 或 `day_offset`。
- `day_offset` 规则：今天=0，明天=1，后天=2；能算出具体日期时优先填 `date=YYYY-MM-DD`。
- 回复时用自然中文总结关键点：当前天气、温度、体感、降雨、未来变化，以及必要的出行提醒。
- 不要输出原始 JSON、认证信息、API Host、JWT、私钥路径。
